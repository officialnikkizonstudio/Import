# Portfolio Narrative Architect

Portfolio Narrative Architect is a browser-based web app that helps creatives transform portfolios from image galleries into strategic case studies.

## What it enforces

Each case study requires:
- Strategic problem definition
- Market context
- Risk level and mitigation
- System thinking (stakeholders, dependencies, tradeoffs)
- Long-term impact
- Evidence and outcomes

## Features

- Structured narrative builder with required sections
- Strategic Narrative Score (0-100 style rubric)
- Local persistence via `localStorage`
- Portfolio feed with rich narrative cards
- Export all case studies to JSON
- Export individual case studies to Markdown

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
